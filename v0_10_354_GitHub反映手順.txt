JEWELRY×JEWELRY v0.10.354 GitHub反映手順

1. GitHub DesktopでJEWELRY×JEWELRYのリポジトリを開きます。
2. 「JEWELRYxJEWELRY_v0_10_354_GitHub差し替えデータ.zip」を展開します。
3. 展開されたファイルとフォルダを、リポジトリのルートへ上書きコピーします。
4. GitHub Desktopで変更内容を確認し、コミットします。
5. Push originを押します。
6. GitHub Pagesを開き、更新されない場合はページを再読込します。
7. PWA版に古い音が残る場合は、アプリを完全終了して再起動するか、ブラウザのサイトデータ／Service Workerキャッシュを更新します。

主な確認箇所
・コンビニでサイクロプスイベントが発生すると、キャラクター表示直後にバーコードリーダー風の「ピッ・ピッ」が鳴ること
・サイクロプス登場時に従来のインパクト音が重なって鳴らないこと
・寿司屋の大将イベントの登場音は従来どおりであること
・効果音ミュート時にはバーコード音が鳴らないこと
