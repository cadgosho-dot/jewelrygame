JEWELRY×JEWELRY v0.10.618 GitHub Desktop更新手順

1. GitHub Desktopで jewelrygame リポジトリを開きます。
2. 更新ZIPを展開します。
3. ZIP内のファイル／フォルダをリポジトリ直下へ上書きコピーします。
4. Changesで差分を確認します。
5. Commit名: Update to v0.10.618
6. Commit to main → Push origin を実行します。

確認ポイント:
- 既存の映画館イベントが従来どおり独立していること。
- 見習い職人イベントは別イベントとして土日の御徒町入場時だけ抽選されること。
- 職人スタッフ雇用後は見習い職人イベントだけが停止し、既存映画館イベントには影響しないこと。
