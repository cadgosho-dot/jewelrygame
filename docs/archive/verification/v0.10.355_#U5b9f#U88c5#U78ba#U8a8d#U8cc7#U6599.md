# JEWELRY×JEWELRY v0.10.355 実装確認資料

## 実装内容

### ボムじいさん／パズーパンイベント

- 従来「人物」として扱っていたキャラクター名を「ボムじいさん」に確定しました。
- イベント画面上部を「ボムじいさん」へ変更しました。
- 入手通知文にも「ボムじいさん」を反映しました。
- 新規効果音 `assets/audio/sfx-bomb-jii-appear.ogg` を追加しました。
- 新規発生時、キャラクター表示直後に導火線のチリチリ音と小さな爆発音を1回再生します。
- パズーパン受取時の成功音は従来どおり維持しています。

### 人魚イベント

- 新規効果音 `assets/audio/sfx-mermaid-splash.ogg` を追加しました。
- 新規発生時、人魚表示直後に水しぶき、泡、きらめきを組み合わせた音を1回再生します。
- パール受取時の既存きらめき音は維持しています。

### 通りすがりのクイズ王

- 新規登場音 `assets/audio/sfx-quiz-intro.ogg` を追加しました。
- クイズ王が現れた直後に、短いクイズ番組風ジングルを再生します。
- 新規問題表示音 `assets/audio/sfx-quiz-question.ogg` を追加しました。
- 2回目の会話から4択問題へ切り替わる瞬間に再生します。
- 正解後に原石報酬が表示される瞬間、既存のきらめき音を再生します。
- 既存のクイズBGM、正解専用音、不正解専用音は変更していません。
- 会話送りの選択音が二重に鳴らないよう、クイズ会話の音を遷移処理側で個別制御しています。
