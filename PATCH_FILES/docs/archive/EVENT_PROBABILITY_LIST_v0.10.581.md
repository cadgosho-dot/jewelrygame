# Event Probability List v0.10.581

## Meaning of fraction probabilities

- `1 / 15`: about one occurrence per fifteen eligible random checks (about 6.67%).
- `1 / 30`: about one occurrence per thirty eligible random checks (about 3.33%).
- `1 / 40`: about one occurrence per forty eligible random checks (2.5%).
- `1 / 60`: about one occurrence per sixty eligible random checks (about 1.67%).
- `1 / 90`: about one occurrence per ninety eligible random checks (about 1.11%).
- `1 / 100`: about one occurrence per one hundred eligible random checks (1%).
- `1 / 200`: about one occurrence per two hundred eligible random checks (0.5%).
- `1 / 365`: about one occurrence per three hundred sixty-five eligible random checks (about 0.27%).

These are random probabilities. They do not guarantee an event exactly on the 15th, 30th, or 90th check.
