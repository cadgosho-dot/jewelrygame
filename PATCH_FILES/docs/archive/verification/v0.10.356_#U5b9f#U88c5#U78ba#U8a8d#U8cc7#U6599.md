# JEWELRY×JEWELRY v0.10.356 実装確認資料

## 実装内容

### ウエスタン・ユニオン／アンティークダイヤイベント

- 新規登場音 `assets/audio/sfx-western-union-arrival.ogg` を追加しました。
- 年次イベントが新規発生し、使者のキャラクターが表示された直後に1回再生します。
- 音は電信機の機械的な打鍵音と古いベルを組み合わせ、ウエスタン・ユニオンの使者らしい短い演出にしています。
- セーブからイベントを再開した場合は、登場音を繰り返し再生しません。

### アンティークダイヤの受け渡し

- 新規受け渡し音 `assets/audio/sfx-western-union-handover.ogg` を追加しました。
- 選択肢で「そうだけど」を選んだ時、電報・書類を手渡す紙音と留め具音を再生します。
- 既存のアンティークダイヤきらめき音は維持し、受け渡し音と重なりすぎないよう230ミリ秒後に再生します。
- 報酬追加処理と通知は従来どおりです。

### 音を追加しなかった場面

- 「いいえ」は不正解や失敗ではないため、エラー音や不正解音は追加していません。
- 「いいえ」と会話送りには、従来の共通選択音が鳴ります。
- 雨の環境音は既存のメイン画面用雨音をそのまま使用します。
