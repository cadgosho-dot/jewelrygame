# 謎の中華料理イベント 固定仕様

承認版: v0.10.686

## 発生条件
- 既存仕様を維持。発生条件・抽選率・日次抽選制御は変更しない。
- 料理画像は既存の2種類を使用し、直前と同じ料理を避ける既存ロジックを維持。

## 進行
1. 導入動画（既存動画。contain / crop禁止 / 黒余白）
2. 会話3段階
3. 謎の中華料理を表示
4. 「15,000円」大きい赤文字
5. 「タップして食べる」を別行表示
6. タップ時点で所持金から15,000円を一度だけ差し引く
7. 食事効果音を再生
8. 効果音後、中華料理屋背景＋料理人を再表示
9. 「また来いよ！オマエ美味そうだからな、、、、」
10. タップで通常メイン画面へ戻る

## UI
- セリフ枠内は透明。曇り・背景色・blurなし。
- 料理提供の枠内も透明。
- 中華料理だけは報酬/提供画像の上下浮遊アニメーションを使用しない。食べ物は机上の固定物として扱う。
- 料理人は縦画面で承認された補正版PNGを縦横共通で使用。内部の誤透明抜けを補正済み。
