# JEWELRY×JEWELRY v0.10.353 実装確認資料

## 寿司屋の大将イベント
- 回転寿司を選択した時に約1/90で発生します。
- 同じゲーム内日付では1回だけ抽選します。
- 1回目のセリフへプレイヤー名を差し込みます。
- 2回目のセリフ後、無料回転寿司へ移動します。
- 皿数・食事音・空腹回復は通常どおり、画面金額と精算金額は0円です。
- 会計後に「またこいよ！」を表示し、タップするとメイン画面へ戻ります。

## サイクロプスイベント
- コンビニを選択した時に約1/90で発生します。
- 同じゲーム内日付では1回だけ抽選します。
- 2段階の会話後、栄養ドリンク画像をタップして受け取ります。
- 受取後は通常のコンビニ食事処理へ移動します。

## 栄養ドリンク
- アイテム欄へ追加されます。
- 使用すると1個消費して空腹度が3回復します。
- 空腹度7の時は使用できず、消費しません。

## 効果音
- イベント登場：インパクト音
- 会話タップ：選択音
- 無料開始・受取・無料会計：成功音
- 通常回転寿司会計：コイン音
- 栄養ドリンク使用：飲食音＋回復成功音
- 回転寿司で寿司を食べる音は既存ミニゲームの食事音を継続使用します。

## 効果音の配置

- 両イベントの出現時：インパクト音
- セリフを進める時：既存の選択音
- 大将のおごり開始時：成功音
- 無料回転寿司のお会計時：成功音（重複再生なし）
- 通常回転寿司のお会計時：硬貨音
- 栄養ドリンク受取時：成功音と振動
- 栄養ドリンク使用時：飲食音の後に短い成功音と振動
- 大将イベント終了後：食事完了音
