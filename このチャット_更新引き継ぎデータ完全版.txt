2. 3Dメガネ縦画面不具合
============================================================

特定プレイヤーのAndroid縦画面で、
3Dメガネイベント人物画像が巨大表示され、
顔の一部だけが画面いっぱいに表示される問題が発生。

確認時:
- v0.10.741の縦画面安全CSSはmainに残っていた
- サービスワーカーはv0.10.748だった
- 特定端末だけで再発していた

考えられた主原因:
1. 古いService Worker / キャッシュの混在
2. 古いAndroid Chrome / WebViewで
   CSSの min() / dvh が正しく解釈されない

v0.10.749で追加した考え方:
- 3Dメガネイベントだけに限定
- width: 90%
- max-width: 430px
- max-height: 72vh
- min() / dvhだけに依存しない
- hosting-origin-guard.jsからも互換CSSを注入
- viewport-shell.js側からも通常ブラウザ時に補助
- sw.jsでversioned script/style取得時にHTTPキャッシュを再利用しにくくした

重要:
この旧Android互換修正は今後も削除しない。

3. 思い出画面
============================================================

既存の思い出仕様は維持。

主な仕様:
- スマホ → アイテム → 装備品の後に「思い出」
- 実際に会ったキャラクターだけ表示
- ??? / ロック表示なし
- カード内:
  画像
  名前
  短い説明
  出会った回数
  報酬は取得済みのときだけ
- 「報酬なし」は表示しない
- キャラクター画像・報酬画像はタップで拡大
- 拡大画像は「閉じる」ボタンだけで閉じる
- 人物画像は枠に触れない範囲でできるだけ大きく
- object-fit: contain
- カード内部・枠内部は透明
- 背景固定
- 画面全体はスクロールさせず、リスト部分だけスクロール
- 横画面2列、縦画面1列
- 横背景と縦背景は別
- ボムじいさんだけ人物画像を少し暗くする
- 将来の新キャラは自動記録
- 出会った回数を表示
