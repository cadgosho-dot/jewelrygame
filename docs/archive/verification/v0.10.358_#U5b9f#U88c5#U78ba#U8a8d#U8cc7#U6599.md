# JEWELRY×JEWELRY v0.10.358 実装確認資料

## 今回の実装内容
- ハンバーガー屋の一回限りイベント「観光客→木刀入手イベント」を追加しました。
- 発生条件は以下です。
  - 店舗を所持している
  - ゲーム内プレイ日数が365日以上
  - 木刀を未所持
  - まだイベント未発生
- イベントの流れ
  1. ハンバーガー屋を選ぶと観光客が登場
  2. 「コンニチハ！ゲンキデスカ！」
  3. 「浅草はどうやって行けば良いですか？」
  4. 選択肢「東京メトロ上野広小路駅から銀座線に乗る」
  5. 「サンキュ、ありがとうございます！これあげますよジャパニーズ！」
  6. 木刀をタップして受け取る
  7. 「神のご加護を！」
  8. 通常の食事画面へ戻る
- 木刀はスマホの「アイテム」に追加されます（使用不可の護身アイテム表示）。
- 木刀所持中は強盗イベントの発生率が半分になります。

## 簡易確認手順
1. セーブデータで「店舗所持」「365日以上」にした状態で食事→ハンバーガー屋を選択。
2. 観光客イベントが始まることを確認。
3. 木刀受け取り後、スマホ→アイテムに木刀が表示されることを確認。
4. 同条件でも2回目以降はイベントが再発しないことを確認。
5. 木刀所持時、強盗判定が通常の 1/100 から 1/200 になることをコード上で確認。
