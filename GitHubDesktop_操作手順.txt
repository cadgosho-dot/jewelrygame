GitHub Desktop 操作手順

1. GitHub Desktopを開く
2. Current Repository:
   cadgosho-dot/jewelrygame
3. Fetch origin
4. Pull origin が出た場合はPull
5. Repository > Open in Terminal
6. 次を実行:
   python "（展開した更新データ）/scripts/apply_update.py"
7. 検証:
   python "（展開した更新データ）/scripts/verify_update.py"
8. GitHub Desktopへ戻る
9. Changesを確認
10. Commit message:
    v0.10.751 3Dメガネとストーリーテラー画像を最新化
11. Commit to main
12. Push origin

Commit前に見るポイント:
- 3Dメガネ画像が新規v751
- ストーリーテラー画像が新規v751
- app.jsは画像参照2箇所が変更されている
- memories-screen.jsは思い出画像2箇所が変更されている
