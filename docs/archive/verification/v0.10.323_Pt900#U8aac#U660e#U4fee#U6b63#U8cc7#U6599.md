# v0.10.323 Pt900説明修正資料

## 修正方針
- 日本国内のジュエリー用Pt900はPt90％・Pd10％のPt–Pd系を基本として説明。
- 硬さ・形状保持性・組織調整のため、Pdの一部をRuへ置換したハードPt900も記載。
- Pt900/Ir 90/10を日本の代表例として扱っていた前版の説明を削除。

## 代表例
- Pt90・Pd10：比重 約19.8～19.9、硬さ 約80 HV、溶融範囲 約1740～1755℃
- Pt90・Pd9・Ru1：比重 約20.0～20.24、硬さ 約100 HV、溶融範囲 約1750～1770℃
- Pt90・Pd8・Ru2：国内鋳造材の公開配合例あり

数値は配合、加工率、焼鈍条件、鋳造状態で変わるため、購入材の技術資料を優先します。
