# JEWELRY×JEWELRY v0.10.694

## 正式実装
- エメラルド班班長／ケバブイベントの承認済み縦・横レイアウトを本番へ反映。
- エメラルド8種の商品画像は透明余白をクロップし、確認済みサイズへ拡大。
- ショーケースへ合計価格を赤字で表示（価格は `eventState.gemTotalPrice` から動的表示）。
- 「タップして進む」はショーケースの右下へ配置。
- 「エメラルドを購入した」はセリフから分離し、中央の黄色・枠付き結果メッセージとして表示。
- 「これでケバブも美味しいわ....」は通常の会話本文として表示。
- 発生条件は既存仕様を維持：エメラルド合計価格 + ケバブ代を所持している場合のみ抽選対象、確率1/30。
