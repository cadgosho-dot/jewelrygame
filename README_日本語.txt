【更新手順】
1. ZIPを展開してください。
2. GitHub Desktopで jewelrygame / main を開き、Fetch origin、表示された場合は Pull origin を押してください。
3. Repository → Show in Explorer（MacはShow in Finder）でゲームのフォルダを開いてください。
4. 展開したZIP内の「FILES」フォルダの中身を、ゲームのフォルダへコピーし、同名ファイルを置き換えてください。
   「FILES」フォルダそのものをコピーするのではなく、中のVERSION、js、assetsなどをコピーします。
   既存フォルダを削除せず、中身を結合してください。
5. GitHub DesktopのSummaryへ「v0.10.949 ウーパールーパー追加」と入力し、Commit to main → Push originを押してください。
6. GitHub Actionsの公開処理が終わったら、ゲームを開き直してください。表示バージョンは0.10.949です。

コピー前に、手元のVERSIONが0.10.948であることを確認してください。
