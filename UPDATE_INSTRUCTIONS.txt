【使い方】
1. GitHubの jewelrygame リポジトリをローカルで最新版(main)にしてください。
2. このZIP内の「COPY_TO_REPOSITORY_ROOT」フォルダを開きます。
3. 中身を jewelrygame リポジトリのルートへ、そのまま上書きコピーしてください。
   ※ COPY_TO_REPOSITORY_ROOT フォルダ自体を入れるのではなく「中身」をコピーします。
4. 既存の他ファイルは削除しないでください。
5. 変更内容を確認後、mainへCommit / Pushしてください。
6. GitHub Actions「地金相場更新とGitHub Pages公開」の validate-build が成功し、
   「CURRENT BUILD AUDIT: PASS」になったことを確認してください。
7. build-pages / deploy-pages まで成功したら本番反映完了です。
