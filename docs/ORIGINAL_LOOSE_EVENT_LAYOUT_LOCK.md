# オリジナルルースイベント — 承認済みレイアウト固定仕様

承認版: v0.10.680

このイベントはユーザー実機確認済み。ユーザーから明示的な変更指示があるまで、別画面・別イベント・共通CSS・共通イベント処理の修正で表示や挙動を変更しない。

## 固定仕様

- 発生場所はルース屋。ルース屋入店時の既存抽選フローを維持する。
- イベント背景はルース屋。
  - 横画面: `assets/images/loose-shop-v385.webp`
  - 縦画面: `assets/images/loose-shop-portrait-v385.webp`
- キャラクター画像は `assets/images/events/loose-shop-original-quiz.png`。
  - 輪郭切り抜き
  - 背景透明PNG
  - 3Dメガネの奥の目は見えない
- キャラクター名は `3Dメガネ`。会話枠内で左詰め表示。
- `オリジナルルースイベント` というイベント名ラベルは表示しない。
- 通常会話、正解後、不正解後、正解表示、最後の会話のセリフ枠は画面下詰め。
- 横画面で `左=キャラクター / 右=4択` にするのは4択表示中のみ。
- 縦画面では会話時と4択時でキャラクター座標を共通固定し、セリフ枠/クイズ枠の高さが変わってもキャラクターを上下させない。
- `正解は○○でした` の本文だけ緑色 `#72d88b`。
- `タップして進む` は全イベント共通の小さい補助表示を維持。
- 4択表示中だけ、通りすがりのクイズ王の4択時と同じ `quiz_show_thinking_bgm_60s_loop.mp3` を使用する。
  - 会話中・正解後・不正解後・報酬画面ではルース屋の通常BGMへ戻す。
- 正解時のオリジナルルース獲得フローは既存仕様を維持。

## 回帰防止

- このイベントのレイアウト変更は必ず `body[data-screen="looseShopOriginalQuizEvent"]` 以下に限定する。
- 共通 `.okachimachi-quiz-event` / `.quiz-character-area` / `.quiz-dialogue-panel` / `.quiz-question-panel` を変更する場合、この固定仕様への影響を確認する。
- `通りすがりのクイズ王` の固定仕様 (`docs/QUIZ_KING_LAYOUT_LOCK.md`) は別ロックとして維持し、本イベントの変更で触らない。

- v0.10.682: 「タップして進む」はタトゥーの女イベントと同じ右寄せ・小さめ・約2pxの穏やかな上下アニメーションを固定。
