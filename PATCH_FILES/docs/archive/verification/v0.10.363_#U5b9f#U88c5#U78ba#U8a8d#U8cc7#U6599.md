# JEWELRY×JEWELRY v0.10.363 実装確認資料

## 実装内容
- 累計の原石研磨回数を保存し、50回到達後の次回インド料理屋利用時に一度だけイベントを発生させます。
- インド料理屋店長の会話を実装しました。
  1. 「あ、○○○こんにちは、頼まれてたもの用意できましたよ。」
  2. 「これでダイヤモンドも研磨できますね。」
  3. 研磨盤をタップして受け取る
  4. 「また何か必要だったら相談してくださいね。」
- 「ダイヤモンド研磨用平面研磨盤」を工房の工具・設備へ追加します。
- 通常設備名を「宝石研磨用平面研磨機」へ変更しました。
- 専用研磨盤の入手前は、採掘・宇宙採掘・クイズ報酬でダイヤモンド原石が出ないようにしました。
- 専用研磨盤の入手後に、ダイヤモンド原石の採掘と研磨を解禁します。
- ダイヤモンド研磨時、1/50の確率で専用研磨盤が故障します。
- 故障時はg-Lab.で50,000円、7日間の修理に対応します。
- イベント自体はゲーム内時間を消費しません。
- 既存セーブ用の初期値と正規化処理を追加しました。
