JEWELRY×JEWELRY v0.10.668 更新手順

1. GitHub DesktopのJEWELRY×JEWELRYプロジェクトを開きます。
2. この更新ZIPの内容をプロジェクト直下へ上書きします。
3. GitHub Desktopで変更内容を確認し、コミット/Pushしてください。
4. PWAを一度起動して更新を反映後、完全終了してからもう一度起動してください。
5. 2回目の起動で「スマートフォン → 設定 → 起動診断 → 診断結果をコピー」を実行してください。

主変更:
- Firebase主要接続先へpreconnectを追加。
- タイトル表示前のBGM・環境音取得を保留し、ゲーム開始後に現在の音場を解放。
- Service Workerの更新確認をwindow load後最低10秒遅延。

非変更:
- クラウドセーブ読込、新旧判定、セッション監視、バックグラウンド保存キュー
- UI、イベント、価格、報酬、発生率、ゲームバランス
