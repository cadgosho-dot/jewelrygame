# タトゥーの女・琥珀イベント 固定仕様

承認版: v0.10.681

このイベントは、川原さんの明示指示があるまで以下の表示仕様を崩さない。

## 共通
- 発生場所: 不動産屋
- 背景: 不動産屋
- 名前表示: 「タトゥーの女」
- 導入動画あり
- 会話 → 琥珀受け取り → 最後の会話 の流れを維持

## 縦画面
- キャラクターは中央寄り
- セリフ枠は下詰め
- セリフ量によってキャラクター位置を崩さない

## 横画面
- キャラクターは従来より大きめ
- キャラクターがセリフ枠へ少しかかってもよい
- レイヤー順は「背景 < キャラクター < セリフ枠 < セリフ文字」
- セリフは常に読みやすさを優先する

## 変更禁止ルール
- 他イベント共通CSSの変更でこのイベントを巻き込まない
- 修正は `body[data-screen="tattooWomanAmberEvent"]` スコープ内でのみ行う
- 別件修正時も、川原さんの明示指示がない限りサイズ感・重なり順・会話配置を変えない
