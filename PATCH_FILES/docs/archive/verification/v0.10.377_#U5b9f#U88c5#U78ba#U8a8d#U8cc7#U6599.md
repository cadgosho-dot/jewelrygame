# JEWELRY×JEWELRY v0.10.377 実装確認資料

## 実装内容
- 店頭に陳列したジュエリーの自動販売に使う基本確率を **24％から19％へ変更**しました。
- 全体として、1商品・1日あたりの販売確率が従来より **5ポイント低下**します。
- 標準的な条件の平均販売確率は、約39.6％から約34.6％になります。
- 来店人数、販売価格、品質、店舗特性、店舗評価、販売員による既存補正は変更していません。
- 最低確率8％、最高確率90％の制限は変更していません。
- 店舗家賃、縦画面背景、ルース屋表示、既存機能、セーブデータ互換性は維持しています。

## 確認手順
1. 店舗を契約し、ショーケースへジュエリーを陳列します。
2. 1日を終了し、店頭販売が商品ごとに判定されることを確認します。
3. 販売価格、品質、店舗評価、販売員などの補正が従来どおり反映されることを確認します。
4. 長期間の試行で、同条件における販売頻度がv0.10.376より少し下がっていることを確認します。
5. 古い処理が残る場合は、PWAを完全終了して再起動し、再読み込みします。
