JEWELRY×JEWELRY v0.10.355 GitHub反映手順

1. GitHub DesktopでJEWELRY×JEWELRYのリポジトリを開きます。
2. 「JEWELRYxJEWELRY_v0_10_355_GitHub差し替えデータ.zip」を展開します。
3. 展開されたファイルとフォルダを、リポジトリのルートへ上書きコピーします。
4. GitHub Desktopで変更内容を確認し、コミットします。
5. Push originを押します。
6. GitHub Pagesを開き、更新されない場合はページを再読込します。
7. PWA版に古い音が残る場合は、アプリを完全終了して再起動するか、ブラウザのサイトデータ／Service Workerキャッシュを更新します。

主な確認箇所
・パズーパンイベントの画面上部に「ボムじいさん」と表示されること
・ボムじいさん登場時に導火線と小さな爆発の専用音が1回鳴ること
・パズーパン受取時には従来どおり成功音が鳴ること
・人魚登場時に水しぶきと泡の専用音が1回鳴ること
・パール受取時には従来どおりきらめき音が鳴ること
・通りすがりのクイズ王登場時に専用ジングルが鳴ること
・問題が表示される瞬間に問題提示音が鳴ること
・正解／不正解時には従来の専用音が鳴ること
・正解後に原石が表示される瞬間、きらめき音が鳴ること
・効果音ミュート時は追加音を含む効果音が鳴らないこと
