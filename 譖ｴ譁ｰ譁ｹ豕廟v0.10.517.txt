v0.10.517 再作成版 更新方法

1. このZIPを展開してください。
2. 展開後に見えるファイルとフォルダーをすべて選択してください。
3. GitHub Desktopで管理している jewelrygame フォルダー直下へコピーしてください。
4. 同じ名前のファイルがある場合は「ファイルを置き換える」を選んでください。
5. GitHub DesktopのSummaryに Update to v0.10.517 と入力してください。
6. Commit to main、続いて Push origin を押してください。

注意
・ZIPの中身はプロジェクト直下の構成です。
・data/metals.jsonは含めていないため、現在の相場データを上書きしません。
・外側のフォルダーごとコピーせず、展開後の中身をコピーしてください。
