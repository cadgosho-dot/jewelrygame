# JEWELRY×JEWELRY v0.10.366 実装確認資料

## 修正内容
- 「今日の宝石」の365種類データを端末側へ確実に反映するため、`daily-gems.js` の読み込みURLへバージョン番号を付与しました。
- Service Workerでも `daily-gems.js` をバージョン付きでプリキャッシュします。
- `daily-gems.js` への通信はキャッシュを優先せず、更新版を取得してから保存する処理に変更しました。
- Service Workerのキャッシュ世代をv0.10.366へ更新し、旧キャッシュを削除します。

## データ確認
- 登録日数：365日
- 宝石ID重複：なし
- 宝石名の完全一致重複：なし
- 2月29日：2月28日の宝石を表示
- 日付基準：ゲーム内カレンダー

## 確認方法
1. GitHub Pagesへ反映後、アプリを一度完全に終了します。
2. 再起動し、必要に応じてページを再読み込みします。
3. ゲーム内の日付を進め、「今日の宝石」が30種類の循環ではなく日付ごとに変わることを確認します。
