# JEWELRY×JEWELRY v0.10.374 実装確認資料

## 実装内容
- 縦画面の背景レイアウト判定を修正しました。
- 専用縦画像がある画面は全面表示を維持します。
- 横長画像しかない画面は、全面背景と横構図を重ねる表示へ戻しました。
- ルース屋の縦画面では、操作パネル類を半透明化し、背景画像が見える濃度へ調整しました。
- 横画面、ゲーム進行、セーブデータ、地金相場データは変更していません。

## 確認手順
1. スマートフォンを縦向きにしてメイン画面を開き、縦専用背景が全面表示されることを確認します。
2. 御徒町、食事、ディスプレイ屋、不動産屋を開き、縦専用背景が表示されることを確認します。
3. 採掘、工房、店舗、g-Lab.、地金屋、ルース屋を開き、背景画像が画面全体と上部の横構図に表示されることを確認します。
4. ルース屋で「ルースを買う」「ルースを売る」「原石を売る」を確認し、背景が見えつつ文字とボタンを読めることを確認します。
5. 横画面へ切り替え、従来の背景表示が維持されていることを確認します。
6. 古い表示が残る場合は、PWAを完全終了して再起動し、再読み込みします。
