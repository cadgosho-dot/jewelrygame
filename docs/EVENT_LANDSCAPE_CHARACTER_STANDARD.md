# 横画面・通常会話キャラクター 共通固定仕様

承認版: v0.10.683

## 目的
イベントを1件ずつ実機確認しながら、承認された共通品質を同一構造のイベントへ横展開する。

## 対象
`visit-character-event` 基盤を使う通常会話イベント。

## 横画面の標準
- キャラクターは大きめに表示する。
- キャラクターは上詰めとし、頭が画面上端で切れないようにする。
- キャラクター下部はセリフ枠へ少しかかってよい。
- レイヤー順は「背景 < キャラクター < セリフ枠 < セリフ文字」。
- セリフの読みやすさを最優先する。

## 対象外
- `is-reward`: 報酬アイテム画面。アイテムのサイズ・配置を変更しない。
- `is-jade-reward`: 特殊報酬画面。
- `is-after` / `is-vanishing`: 消失・結果演出。
- 通りすがりのクイズ王 / オリジナルルース: 専用固定レイアウトのため別管理。

## 運用
1. イベントごとに携帯確認版で確認する。
2. 承認された共通事項はこの標準へ反映する。
3. キャラクター画像の縦横比などで合わない場合だけイベント固有例外を追加する。
4. 既存の固定イベントを共通修正の副作用で崩さない。
