JEWELRY×JEWELRY v0.10.378 GitHub反映手順

1. 「JEWELRYxJEWELRY_v0_10_378_GitHub差し替えデータ.zip」を展開します。
2. 展開した中身を、GitHub Desktopで管理している最新プロジェクトへ上書きします。
3. 過去版のファイルを混ぜず、Changesで差分を確認します。
4. プロジェクト直下で次を実行します。
   python scripts/check-regression-baseline.py
5. 「回帰防止チェック: OK」と表示された場合だけコミットします。
6. 「v0.10.378 更新・引き継ぎ時の回帰防止を必須化」などの内容でコミットします。
7. Push originを実行します。
8. GitHub Pages公開後、PWAを完全終了して再起動します。
9. 縦画面・横画面の背景、イベント人物位置、上部バー、クイズ、ルース屋を実機確認します。
10. エラーや表示崩れがある場合は、完了・引き継ぎ扱いにしません。
