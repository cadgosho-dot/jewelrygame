# JEWELRY×JEWELRY v0.10.376 実装確認資料

## 実装内容
- 1店舗目の月額家賃を **150,000円**へ変更しました。
- 2店舗目の月額家賃を **400,000円**へ変更しました。
- 3店舗目の月額家賃を **700,000円**へ変更しました。
- 不動産屋の契約条件表示と、毎月1日の店舗家賃請求に同じ新料金が反映されます。
- 契約した月の家賃は無料で、翌月以降に請求する既存仕様は変更していません。
- v0.10.375までの縦画面背景修正、ルース屋の透明表示、既存機能、セーブデータ互換性は維持しています。

## 確認手順
1. 御徒町から「不動産屋」を開きます。
2. 1店舗目の契約画面で、月額家賃が150,000円と表示されることを確認します。
3. 1店舗目を契約後、次の店舗契約画面で2店舗目が400,000円と表示されることを確認します。
4. 2店舗目を契約後、3店舗目が700,000円と表示されることを確認します。
5. 契約月には家賃が請求されず、翌月以降の毎月1日に各店舗の新家賃が請求されることを確認します。
6. 古い表示が残る場合は、PWAを完全終了して再起動し、再読み込みします。
