# v0.10.299 修正確認資料

## 修正内容

スマートフォンのAI相談用コピーを軽量化しました。

- 長大なJSONを廃止し、短い日本語形式へ変更
- 基本ゲームルールは削除せず、6分野へ要約
- 現在状況、店舗、進行中注文、主な所持品、工具・設備を収録
- 通知、収支履歴、設定、完了済み注文、顧客履歴、内部情報を除外
- 各所持品一覧は最大件数を制限

## 維持した基本ゲームルール

1. 基本的な遊び方
2. 時間と営業時間
3. 空腹度
4. 採掘
5. 工房・研磨・ジュエリー制作
6. 店舗・注文・御徒町施設

## 非変更項目

- 既存セーブデータ形式
- `data/metals.json`
- ゲーム本体の進行ルール
- 画像・音声・画面表示
