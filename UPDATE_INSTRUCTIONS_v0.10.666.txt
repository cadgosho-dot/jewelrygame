JEWELRY×JEWELRY v0.10.666 更新手順

1. GitHub DesktopのJEWELRY×JEWELRYプロジェクトを開きます。
2. この更新ZIPの内容をプロジェクト直下へ上書きします。
3. GitHub Desktopで変更内容を確認してコミット/Pushしてください。
4. PWAは一度完全終了して再起動してください。
5. 起動後、スマートフォン → 設定 → 起動診断 → 診断結果をコピーし、v0.10.665と比較できます。

主変更:
- Firebase Auth通常起動のpopup/redirect iframeを不要化。
- クラウドセーブとセッション取得を並列化。
- 起動時の地金相場通信を遅延化。
- Service Workerの重い先読みと更新競合を削減。
