# v0.10.356 アンティークダイヤイベント効果音追加

基準版v0.10.355へ、雨の日のウエスタン・ユニオン／アンティークダイヤイベント用の効果音を追加した版です。

- イベントが新規発生し、使者が表示された直後に電信機の打鍵音と古いベルを組み合わせた専用登場音を再生
- 「そうだけど」を選び、アンティークダイヤを受け取る場面に電報・書類を手渡す専用音を追加
- 手渡し音の直後に、従来のアンティークダイヤのきらめき音を少し遅らせて再生
- 「いいえ」は失敗ではないため、専用の不正解音は付けず、従来の選択音のみを使用
- 会話送りの選択音、雨の環境音、報酬内容、発生条件は変更なし
- 新規音源をPWAのプリキャッシュへ追加

セーブデータ構造、イベントの年1回判定、`data/metals.json`は変更していません。


## 更新・引き継ぎ時の回帰防止（必須）

修正済みの画面や仕様を、別の更新で過去状態へ戻さないため、更新・ZIP作成・引き継ぎの前に必ず次を実行してください。

```bash
python scripts/check-regression-baseline.py
```

エラーが1件でも出た状態では、実装完了・ZIP作成・引き継ぎ完了として扱わないでください。詳細は `REGRESSION_PROTECTION_CHECKLIST.md` と `HANDOFF_MANDATORY_REGRESSION_RULES.txt` を確認してください。
