JEWELRY×JEWELRY v0.10.667 更新手順

1. GitHub DesktopのJEWELRY×JEWELRYプロジェクトを開きます。
2. この更新ZIPの内容をプロジェクト直下へ上書きします。
3. GitHub Desktopで変更内容を確認してコミット/Pushしてください。
4. PWAを一度起動して更新を反映し、完全終了後にもう一度起動してください。

主変更:
- 起動時のセッション取得のFirestore応答待ちをタイトル表示条件から外しました。
- 端末セーブが新しい場合のクラウド書き戻しをバックグラウンド化しました。
- クラウド書き戻しは通常保存と同じキューへ並べ、保存順序を維持します。
- クラウドセーブ読み込みと新旧判定は従来どおり起動時に行います。
