JEWELRY×JEWELRY v0.10.665 更新手順

1. GitHub DesktopのJEWELRY×JEWELRYプロジェクトを開きます。
2. この更新ZIPの内容をプロジェクト直下へ上書きします。
3. GitHub Desktopで変更内容を確認してコミット/Pushしてください。
4. 公開後、PWAを一度終了して起動し直してください。
5. タイトルからゲームを開始し、スマートフォン → 設定 → 「起動診断」を開きます。
6. 「診断結果をコピー」を押し、結果をChatGPTへ貼り付けてください。

主変更:
- 起動高速化前の基準計測用「起動診断」を追加。
- この版では起動処理の順序やゲーム挙動そのものは変更していません。
