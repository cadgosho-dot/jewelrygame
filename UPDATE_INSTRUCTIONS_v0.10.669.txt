JEWELRY×JEWELRY v0.10.669 更新手順

1. GitHub DesktopのJEWELRY×JEWELRYプロジェクトを開きます。
2. この更新ZIPの内容をプロジェクト直下へ上書きします。
3. GitHub Desktopで変更内容を確認し、必要なコミット/Pushを行ってください。
4. PWAでは一度起動して更新を反映した後、完全終了して再起動してください。

主変更:
- Firebase初期化前にタイトル画面を先行表示。
- セーブ確認完了まではスタートボタンを「セーブ確認中…」として無効化。
- クラウドセーブ取得・端末/クラウド比較完了後だけスタートを有効化。
- 起動診断を「先行タイトル表示」と「スタート有効化」に分離。

セーブ安全性:
- クラウドセーブ読み込み、新旧判定、保存キュー、セッション監視は従来どおり維持。
