# JEWELRY×JEWELRY v0.10.375 実装確認資料

## 実装内容
- ルース屋の文字や数値を囲んでいた黒い背景を削除しました。
- 石名、価格、所持数、操作部分、タブ、空表示カードを透明表示へ統一しました。
- 背景画像の見え方を維持しながら、文字色、文字影、金色の細い枠線で可読性を確保しました。
- 選択中のタブは黒背景ではなく、薄い金色で表示します。
- v0.10.374で復旧した縦画面背景、横画面、ゲーム進行、セーブデータ、地金相場データは変更していません。

## 確認手順
1. 御徒町から「ルース屋」を開きます。
2. 「ルースを買う」「ルースを売る」「原石を売る」の3つのタブを確認します。
3. 石名、価格、所持数、操作ボタン周辺に黒い塗りつぶし背景がないことを確認します。
4. 選択中のタブが薄い金色で判別できることを確認します。
5. 背景画像が文字枠の後ろまで見え、文字が読めることを確認します。
6. 縦画面と横画面の両方で確認します。
7. 古い表示が残る場合は、PWAを完全終了して再起動し、再読み込みします。
